# 67

Podgląd walki w Broken Ranks: HP, ikony efektów, mini panel drużyny i przeciwników oraz czaty z wyszukiwaniem i filtrowaniem.

**[Pobierz 67 na Windows 64-bit](https://github.com/maksk03/67/releases/latest/download/67.zip)**

1. Pobierz ZIP i wypakuj całą jego zawartość do osobnego folderu.
2. Uruchom `67.exe`. Obok niego pozostaw folder `Program`.
3. W oknie aktywacji wpisz swój klucz otrzymany od właściciela programu.

Program wymaga poprawnej licencji i połączenia z Internetem przy uruchomieniu. Po pierwszej aktywacji zapamiętuje klucz i sprawdza go online przy kolejnych uruchomieniach. Każdy użytkownik ma własne ustawienia. Historia czatów obejmuje bieżącą sesję programu.

Nowsza stabilna wersja pobiera się i instaluje automatycznie przy uruchomieniu, zachowując ustawienia i zapisany klucz. Link do pobrania pozostaje ten sam.

Do przechwytywania ruchu potrzebny jest Wireshark z Npcap lub uruchomienie z uprawnieniami administratora w trybie surowego gniazda. Python nie jest wymagany.

EXE jest bez podpisu cyfrowego. Windows z włączonym Smart App Control może zablokować jego uruchomienie.
